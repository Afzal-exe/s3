CLOUD COMPUTING - LECTURE NOTES
===============================

1. What is cloud computing?
   On-demand delivery of compute, storage and networking over the internet,
   with pay-as-you-go pricing.

2. Service models
   - IaaS : you manage the OS and apps          (e.g. Amazon EC2)
   - PaaS : you manage only your code           (e.g. AWS Elastic Beanstalk)
   - SaaS : you just use the software           (e.g. email, office suites)

3. Deployment models
   Public cloud, private cloud, hybrid cloud, community cloud.

4. Key characteristics (NIST)
   On-demand self-service, broad network access, resource pooling,
   rapid elasticity, measured service.

5. Amazon S3 in one line
   Object storage: buckets hold objects; each object = key + data + metadata.
